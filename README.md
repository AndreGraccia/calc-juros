# Calculadora de Juros + API do Banco Central

Aplicação para consulta e análise de indicadores financeiros utilizando dados oficiais disponibilizados pelo Banco Central, além de ferramentas para simulação de juros e operações

# Sobre o projeto

O projeto tem como objetivo consultar dados econômicos disponibilizados pelo Banco Central e utiliza-los para apresentar históricos, variações e comparações entre diferentes períodos.

Além da visualização dos indicadores, a aplicação permitirá realizar simulações financeiras, como cálculo de juros simples e compostos, utilizando taxas informadas pelo usuário ou dados obtidos de fontes oficiais do Banco Central do Brasil.

# Objetivos

- consumir dados oficiais disponibilizados pelo BC;
- Consultar taxas e indicadores econômicos;
- Exibir historico e variação dos diferentes indicadores;
- Comparar dados entre diferentes períodos;
- Implementar calculos de juros simples e compostos;
- Criar simulações financeiras utilizando taxas oficiais;
- Apresentar os dados de forma visual por meio de gráficos.
